# Frontend HTML temporário

Esta pasta guarda o frontend atual do AxeGestor em HTML, CSS e JavaScript puro.

Ela foi trazida para dentro do projeto Java para ficar visível no IntelliJ junto com o backend.

## Como rodar

Com o backend Spring Boot rodando em `http://localhost:8080`, abra:

```text
frontend-html/admin/login.html
```

Ou rode o servidor simples:

```powershell
cd frontend-html/admin
node server.js
```

Depois acesse:

```text
http://localhost:5500/login.html
```

## Próximo passo

frontend-angular/
